# Auction XI 1.1.0-rc1

Implementati i punti concordati: regole ultimo credito e regolarizzazione, cicli random, conclusione validata, correzioni admin, rose pubbliche realtime, Qt.A, checkpoint e ripresa, CSV con ID ufficiale. Modalità, dealer e timer remoti predisposti nel codice e testati localmente.

Migrazione additiva delle vecchie aste; ambiente Python originale non riutilizzato; avvio Windows verificato.

La consegna operativa è locale/LAN. Pubblicazione remota rimandata su richiesta dell'utente, senza server a pagamento. Resta la verifica del CSV sul portale Leghe. Vedi IMPLEMENTAZIONE.md e QA_REPORT.md.
